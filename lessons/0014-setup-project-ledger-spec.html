Hãy cùng nhìn lại bản đồ kiến trúc thư mục để hiểu rõ lý do vì sao dự án chuyên nghiệp lại chia thành domain/ và adapters/:

📁 Giải mã Kiến trúc Phân lớp Thư mục (Modular Architecture)

├── domain/                    # VÙNG LÕI: types.ts, errors.ts, Seam Interfaces (KHÔNG import Supabase/Next.js)

2. Thiết Kế Seam Interface: "Chiếc Ổ Cắm Tiêu Chuẩn"

Một Seam là một Interface thuần TypeScript quy định cách tầng Service giao tiếp với tầng lưu trữ. Bạn tạo file src/modules/ledger/domain/types.ts:

src/modules/ledger/domain/types.ts — Định nghĩa Seam và Data Models
export type AccountType = 'ASSET' | 'LIABILITY' | 'EQUITY' | 'REVENUE' | 'EXPENSE';

export interface Account {
  id: string;
  code: string;        // Ví dụ: '111', '112', '156', '511', '632'
  name: string;
  type: AccountType;
}

export interface LedgerEntry {
  id: string;
  transactionId: string;
  accountId: string;
  debit: number;         // Số tiền Nợ
  credit: number;        // Số tiền Có
  description: string;
  createdAt: Date;
}

// SEAM INTERFACE: Chiếc ổ cắm chuẩn mực cho Repository
export interface ILedgerRepository {
  createAccount(account: Omit<Account, 'id'>): Promise<Account>;
  getAccountByCode(code: string): Promise<Account | null>;
  recordTransaction(params: {
    referenceId: string;
    description: string;
    entries: Array<{ accountId: string; debit: number; credit: number; description: string }>;
  }): Promise<{ transactionId: string; entries: LedgerEntry[] }>;
  getAccountBalance(accountId: string): Promise<number>;
}
